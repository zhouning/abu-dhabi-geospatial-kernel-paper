# 阿布扎比土地利用实验：本机数据恢复与重算记录

## 结论

此前把“论文 Git 仓库未包含数据”误写成“本机没有数据”是不正确的。本机数据工作区已完成核查，公开可复现子集现已随论文仓库发布。

本记录最初将论文仓库中的代码与本机数据工作区连接后，重新运行了当前评价器和规划编译器。随后已将可公开、可最小化复现所需的栅格、检查点、FLUS 可执行文件和 GeoFM-LDN 运行时复制进论文仓库；客户 PostgreSQL、ArcGIS 服务和原始 OSM PBF 均未复制。最终制品由 `reproducibility/MANIFEST.json` 与 `reproducibility/SHA256SUMS` 固定。

## 当前重算结果

历史严格多类别 transition FoM（三种子均值）：

| 年份 | GeoSOS-FLUS | Geospatial Kernel | GeoFM-LDN |
|---:|---:|---:|---:|
| 2023，一步 | 0.1256 | **0.1961** | 0.1619 |
| 2024，两步开环 | 0.1782 | 0.2529 | **0.2708** |

因此不能说 GeoFM-LDN 在所有预测跨度上都最好：Kernel 在 2023 一步比较领先，GeoFM-LDN 在 2024 两步开环比较领先。

2024 年模型差值的空间块 bootstrap 中，GeoFM-LDN − Kernel 的严格 FoM 中位数为 0.0177，95% 区间为 [0.0033, 0.0314]。这是基于公开标签的条件 pipeline 对比，不是独立实地样本显著性检验。

规划编译器在冻结的四目标集合下得到 6 个非支配候选：GeoSOS-FLUS 的
3 个情景和 Geospatial Kernel 的 3 个情景；GeoFM-LDN 的 3 个情景均不在
该条件前沿。该结果只适用于公开生态/道路代理、合成需求动作和冻结的
2024 外生驱动，不能解释为官方规划推荐或政策预测。
